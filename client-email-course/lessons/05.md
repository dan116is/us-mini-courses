# Lesson 5 — Eight templates and send rules

**Time:** 40 minutes to paste into your snippet tool  
**Output:** A single note titled `Client email snippets` plus send rules on the first line.

## Send rules (put at the top of the note)

1. Money, dates, and scope live in email (or the project tool the approver searches). Chat is for files and logistics.
2. Same-day invoices when the trigger fires.
3. Weekly update even when thin.
4. No extra work before a numbered option is chosen.
5. Angry thread: 20-minute delay.
6. After any phone call: 5-line recap.
7. You are not their lawyer. Do not promise legal outcomes.

## The eight templates (short forms)

Copy, then fill. Longer versions live in Lessons 1–4.

### 1. Invoice issue

Subject: `Invoice [####] — [Client] — [Job] — due [date]`

```
Attached invoice [####] for [job/period], $[X], due [date]. PO [n / none]. Pay method on the PDF. Questions on line items: reply here.
```

### 2. Day-7 nudge

Subject: `Re: Invoice [####]…`

```
Checking [####] reached AP ($[X], due [date]). Need W-9, PO, or line split? I’ll resend the same day.
```

### 3. Overdue + pause extras

```
[####] due [date] still unpaid. Reply: paid / scheduled date / missing AP item. I pause extras until current. In-motion scoped work continues through [date].
```

### 4. Weekly update

Subject: `Weekly — [Job] — week of [date]`

```
Shipped:
Next (with dates):
Waiting on you (with consequence):
Scope/money:
Decision (A/B) if any:
```

### 5. Change request

Subject: `Change request — [Job] — [extra]`

```
[Extra] is outside [quoted scope line].
1) Skip  2) Add $[X] + [Y] days  3) Swap for [piece]
I start the extra after you pick a number.
```

### 6. Missed date

Subject: `Date change — [Job] — [old] → [new]`

```
[Deliverable] moves to [new day time timezone]. Why: [one line]. Price/scope otherwise same. Need [nothing/approval by …].
```

### 7. Quick-question fence

```
That’s scoped work. Thursday update / paid change / paid call — which?
```

### 8. Call recap

Subject: `Recap — [Job] — [date] call`

```
Attended: [names]
Decided:
Dates:
Money:
I will:
You will:
```

## Install

Gmail: Canned responses / templates.  
Outlook: Quick parts.  
Apple Mail: a note you paste.  
Do not build a “CRM sequence.” These are human sends.

## Practice week

- Send one real weekly (Lesson 3).
- Convert your next Slack extra into template 5 **once**, even if you later choose option 1.
- Fix one old invoice subject line for the next cycle.

## What this will not do

It will not collect a debtor who has decided not to pay. It will not make a bad SOW good (write shorter scopes). It will not guarantee retainers or a $5k month. It will save you from free work you accidentally volunteered at 6:12pm.

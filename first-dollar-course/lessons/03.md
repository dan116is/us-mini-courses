# Lesson 3 — A sales page that does not lie

**Time:** 90 minutes  
**Output:** `index.html` or a Google Doc that can be exported/hosted. One screen is enough.

## Job of the page

Answer five questions so a careful US buyer can say yes or leave:

1. What file do I get?
2. Is it for my situation?
3. What is not included?
4. What does it cost and how do I pay?
5. What happens after I pay?

Anything else is optional flavor.

## Outline (paste and replace)

**Kicker:** Digital download · text · no video  

**Title:** same as the PDF cover  

**One paragraph:** who it is for + the Friday problem  

**Price:** $9 / $19 / $29 [your method]  

**What’s inside:** 4–7 bullets that map to real headings in the file  

**What’s not inside:** 3 bullets (calls, custom league rules, updates forever)  

**Who should skip this:** 2 bullets  

**How to buy:** numbered steps (Lesson 4 fills the payment rails)  

**Fulfillment:** “I email the file after the payment confirms, usually within one business day.” (Write the true SLA you will keep. If you only check email in the evening, say so.)  

**Guarantee:** file resent if unreadable. No outcome guarantee.  

**Contact:** email only  

## Claims you will not make

- Income (“make this back in a day,” “$5k month”)
- Fake scarcity (“17 seats”)
- Fake social proof
- “Includes video” if there is no video
- “Certified” / “accredited” unless a real body said so

If you have one real user (your assistant coach), you may say “I wrote this for our rec team in 2025 and cleaned it for strangers.” That is proof. “Trusted by coaches nationwide” is not.

## Microcopy that reduces refunds and anger

- State file type (PDF, 9 pages, US letter).
- State they need a way to open PDF (Preview, Adobe, phone).
- State personal-use license in one line.
- State you are not their lawyer/CPA/doctor if the topic brushes those.

## Optional: a 120-word version for an email or Craigslist-style post

```
[Title] is a [N]-page PDF for [buyer] who needs [problem] this week.
You get: [3 bullets].
You don’t get: a call, custom work, or a membership.
Price: $[x]. Pay [method]. I email the file when it confirms.
If the file won’t open, I resend. That’s the guarantee.
```

Use this when you do not have a host yet. A page is nicer; an honest email still sells a $9 sheet.

## Visuals

A clean HTML page with system fonts is enough. No stock photos of people high-fiving. If you screenshot a page from the PDF, blur any made-up personal data that looks too real.

## Done when

Every bullet on the page exists in the file. Every IN/OUT from the SKU card appears. Price and fulfillment match Lesson 4.

# Lesson 2 — Write and package the file

**Time:** 3–6 hours split across two days  
**Output:** `SKU-title-v1.pdf` (or zip) with a cover line, version, and license.

## Writing order (do not start at the introduction)

1. **Contents list** (what a buyer can steal today).
2. **The worked example** (one filled-in sample).
3. **The blank template**.
4. **The how-to in numbered steps**.
5. **Cover + who it’s for / not for**.
6. **Version, date, contact email**.

Intros last because they lie until the middle exists.

## Length by price

- **$9:** 1–3 pages. One checklist + 10-line how-to. Worked example can be a second page.
- **$19:** 4–8 pages. Add 3 copy-paste emails or a one-week calendar.
- **$29:** 8–15 pages. Add a troubleshooting section (“if X, do Y”) and one “week at a glance.”

If you overflow 15 pages, you are writing a course. Cut the history of your opinions.

## Page recipe (playbook tier)

**Page 1 — Cover**  
Title, one-sentence promise, “digital file, v1.0, date,” price they already paid (so the PDF matches the page).

**Page 2 — Who / not who**  
Three bullets each. Borrow from the SKU card.

**Page 3 — How to use this in 30 minutes**  
Not “read everything.” A sequence: print page 5, fill the blanks, send email 1.

**Middle — The asset**  
Numbered steps. Checkboxes. Tables with empty cells. Write in second person (“You print the shot list before the tenant arrives”).

**Worked example**  
Invent a realistic US name and city if you cannot anonymize a real one. Never include a real tenant SSN, a real child’s full name, or a real account number.

**Last page — License + contact**  
Personal use or one organization up to five people. No resale of the PDF as a competing product. “Questions about a broken file: [email]. Not a phone consult.”

## Tone

US plain English. Short sentences. No fake case studies. If you have not sold this SKU before, do not write “used by 400 teams.” Write “I used this pattern as a [role] in [year].”

## Tools that do not eat the week

- Google Docs or Word → export PDF.
- Google Sheets for a checklist that needs columns → download `.xlsx` and also PDF the first sheet.
- Zip if you have two files: `title-v1.zip` containing `readme.txt` + the PDF.

`readme.txt` (five lines):

```
Product: [title]
Version: 1.0
Date: [ISO date]
What to open first: [filename]
Broken file? Email [address] with your tx or receipt.
```

## Filename

`northside-move-in-photo-checklist-v1.pdf`  
Not `final_FINAL2.pdf`. Buyers forward files; the name is part of the product.

## Quality bar (30-minute edit)

Read once for:

- Broken promises vs the IN list
- Steps that assume a tool you did not name
- Any “obviously”
- Any advice that is actually legal/tax/medical — relabel or delete

Then export. Lesson 3’s sales page must match this file. If you add a chapter later, that is v1.1 next month, not this Friday.

## Done when

The file opens on your phone. Page count matches the SKU card ±2 pages. License and contact are on the last page.

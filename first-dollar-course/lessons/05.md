# Lesson 5 — The actual Monday–Friday calendar

**Time:** one calendar week  
**Output:** File live, page live, one payment path tested. Optional: one paid order from someone who is not you. Not required to “pass.”

## Stop rule

If a task is not on this calendar, it is next month. No logo, no lead magnet funnel, no YouTube.

## Monday — Choose and outline (≤ 2 hours)

- Lesson 1 SKU card. Kill extra ideas.
- Contents list for the file (Lesson 2 step 1).
- Register the slug and the filename.
- If payment Path A/B is not already usable, decide now. Do not leave checkout to Friday.

## Tuesday — Write the middle (≤ 3 hours)

- Worked example + blank template + numbered steps.
- No cover yet.
- End when the buyer could do the task with only those pages.

## Wednesday — Wrap the file (≤ 2 hours)

- Cover, who/not who, license, export PDF, open on phone.
- Start the sales page outline.

## Thursday — Page + checkout (≤ 3 hours)

- Finish `index.html` or the host you already have (Carrd, a GitHub repo README, a Google Doc published to web — pick one you know).
- Payment steps live.
- Test order path.
- Fix the first confusing sentence.

## Friday — Ship (≤ 2 hours)

- Read page vs PDF once.
- Announce in **one** place you already have: an email list of 20 people, a Facebook group you actually help, a Slack of local owners, or 10 personal notes. Not 30 platforms.
- Message (honest):

```
I wrote a short PDF for [buyer] who needs [problem].
It’s [N] pages, $[price], delivered by email.
If that’s you, the page is [link]. If not, ignore.
```

- Close the laptop at the time you set. v1.1 is allowed next month if someone pays and asks a good question.

## If Friday arrives and the PDF is still thin

Ship the $9 version. Change the page. Do not skip shipping to protect a $29 fantasy.

## After the first order

- Fulfill the same day if you said you would.
- Ask one question: “Which page did you use first?” That is your v1.1 cue.
- Do not add a Slack community.

## What “worked” means

Worked = a finished SKU with a true sales page and a checkout you tested. A paid stranger is a bonus, not a grade. There is no first-dollar guarantee. There is a first-file standard.

## Final checklist

- [ ] SKU card with OUT list
- [ ] File opens on a phone
- [ ] Page matches file
- [ ] Payment instructions name the network/method twice
- [ ] Order email template posted
- [ ] One test of the path
- [ ] One announcement in a place you already exist

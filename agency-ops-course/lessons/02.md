# Lesson 2 — Write SOPs a Tuesday temp can follow

**Time:** 90 minutes  
**Output:** Three one-page SOPs for the steps you circled in Lesson 1.

## Standard that matters

A usable SOP is not a novel. It is a page a competent adult can follow **without Slack-ing you** if you are at a dentist appointment on Tuesday.

If the document requires tribal knowledge (“use the usual deck”), it is not an SOP. It is a reminder to you.

## The one-page SOP template

Copy this block for each of your three targets.

```
SOP TITLE:
LANE: Demand / Commit / Deliver / Collect
OWNER (role, not a nickname):
BACKUP:
TOOL OF RECORD (one):
TRIGGER (what starts this):
DONE WHEN (observable):

STEPS:
1.
2.
3.
4.
5.

IF/THEN:
- If client does not reply in 2 business days →
- If the file is missing →
- If this would change price or deadline → stop and use the Change Request path

QUALITY BAR (what “good” looks like in one sentence):
DO NOT (common shortcuts that create rework):
```

**Five steps max.** If you need twelve, you have two SOPs, or you are documenting a tool instead of a job.

## How to write from reality

Open one real example (a proposal you actually sent, an invoice that actually paid, a kickoff email that actually started work). Rewrite that example as numbered steps. Then delete anything that was “because it was a friend.”

Read the draft out loud. Every time you say “obviously,” add a sentence. Tuesday temps do not share your obviously.

## Three SOPs most 1–5 person US agencies need first

You may substitute if Lesson 1 circled different pain. These are the usual three.

### SOP A — First human reply (Demand)

- **Trigger:** Inbound email, form, or voicemail.
- **Done when:** A human reply is in the same thread with a next step (call booked or three written questions).
- **Quality bar:** Same-day during business hours; next business morning if after 4pm local.
- **Do not:** Let the CRM auto-reply be the only reply.

Starter steps:

1. Check the shared inbox at 9:30am and 3:30pm local (set phone alarms).
2. If it is a current client, label it Client and route to the Delivery owner.
3. If it is new, reply with the “intake three questions” email (below) and offer two call windows this week.
4. Log the lead on the scoreboard (Lesson 3) as New / Waiting / Call booked.
5. If not a fit, send the polite no and archive. Do not keep “maybe” in the pipeline for a month.

**Intake three questions (paste):**

> Thanks for writing. To see if we’re the right shop, I need three facts: (1) what “done” looks like in one sentence, (2) your deadline, (3) whether this is a one-time project or an ongoing monthly. If those are a fit, I can talk Thursday 10:00–10:25am or Friday 2:00–2:25pm [your timezone]. Which works?

### SOP B — Scope lock before work starts (Commit)

- **Trigger:** They said yes, or “let’s start.”
- **Done when:** Signed one-pager (or e-sign) + deposit recorded **or** written PO with billing contact, if that is how that client buys.
- **Quality bar:** Work does not start in Google Drive until the lock exists.
- **Do not:** “We’ll paper it later.” Later is how Friday becomes unpaid.

Starter steps:

1. Send the one-page scope (deliverable, rounds, timeline, price, what is out).
2. Name the client’s single approver.
3. Collect deposit per your posted terms (common pattern: 50% to start for project work; monthly in advance for retainers — pick one and print it).
4. Create the job folder from the template: `/Client/Job/01-admin 02-working 03-sent`.
5. Send kickoff date and the weekly-update weekday you will use (see client-email-course if you also run client comms).

### SOP C — Invoice and 7-day follow-up (Collect)

- **Trigger:** Milestone complete **or** monthly retainer date.
- **Done when:** Invoice is in the client’s AP email, numbered, with PO if they require one.
- **Quality bar:** Same calendar day as the trigger, not “when I remember on Sunday.”
- **Do not:** Bundle three months because you were busy.

Starter steps:

1. Confirm the billing email and PO (if any) from the scope lock file.
2. Issue invoice with job name, period, and due date (Net 15 is a reasonable default if you have not published terms; state your actual terms).
3. Email with the invoice attached or linked; subject line: `Invoice [number] — [Client] — [Job] — due [date]`.
4. Calendar a follow-up for day 7 if unpaid.
5. At day 7, send the short nudge (Lesson 3 scoreboard marks it red). Pause new optional work if that is your posted policy — do not invent policy mid-anger.

## Review rule

Each SOP gets a **backup named person** (or “owner’s spouse / VA / contractor X”). If you cannot name a backup, the SOP is still useful — it is the document you hand a contractor in a pinch. Write the backup as a role if the human does not exist yet: “Delivery backup: contractor on the bench.”

## Done when

Three SOP pages exist in the same folder as the work map. Each has a trigger, a done-when, and five or fewer steps. You have sent yourself a calendar invite to use SOP A tomorrow morning at 9:30.

Lesson 3 hangs these SOPs on a week, so they get used instead of archived.

# Lesson 1 — Map the real work, not the org chart

**Time:** 60–90 minutes this week  
**Output:** A one-page “work map” of how money actually moves through your shop.

## Why this lesson exists

Most 1–5 person US agencies have job titles that lie. “Account manager” is also sales, QA, and the person who chases Net-30 invoices. SOPs fail because they describe the org chart you wish you had, not the path a job takes from first email to deposited check.

This course is about a **weekly operating rhythm**. You cannot cadence what you have not named.

## The four lanes every small shop already has

Write these four headings on a page (paper is fine):

1. **Demand** — how a stranger becomes a conversation (referrals, inbound form, LinkedIn, a partner CPA).
2. **Commit** — how a conversation becomes a paid scope (proposal, signed SOW, deposit, kickoff).
3. **Deliver** — how scope becomes something the client can use (drafts, reviews, live work, QA).
4. **Collect & keep** — how finished work becomes cash and a next period (invoice, follow-up, renewal, referral ask).

If a task does not sit in one of these lanes, it is either overhead (bookkeeping, tools, hiring) or it is theater.

## Exercise: last month’s jobs, not theory

Open last month’s sent invoices. Pick **three closed jobs** (or retainers that billed). For each job, fill this table. Times are approximate; honesty beats precision.

| Field | Job A | Job B | Job C |
|---|---|---|---|
| How they found you | | | |
| First human reply (hours) | | | |
| Days to signed scope | | | |

| Who actually did the work | | | |
| How many review rounds | | | |

**Rule:** if two of three jobs waited more than 48 hours for a first human reply, your Demand lane is leaking. If review rounds exceeded what the SOW allowed, Delivery is undefined. If invoice-to-paid is over 21 days on average, Collect is not a process; it is hope.

## The “sticky note” map

On a whiteboard or a Google Doc, draw four columns (Demand / Commit / Deliver / Collect). Under each column, list **only the steps that happened on those three jobs**. Then circle:

- Steps that only you can do
- Steps that wait on the client
- Steps with no owner (everyone assumed someone else)

Those three circles are next week’s SOP list (Lesson 2). Do not write SOPs for steps that never happen.

## US-specific notes (plain language, not legal advice)

- If you take cards or ACH, name the processor and who reconciles it. “Stripe is set up” is not a Collect lane.
- If you work W-2 plus 1099 contractors, mark which delivery steps a contractor is allowed to touch (client Slack? source files? PII?). Put that on the map now so Lesson 2 does not invent a fantasy.
- Sales tax on services varies by state. You do not need to solve tax in this lesson. You do need a line on the map: “Who sends the invoice and in which tool.”

## Meeting script: 25-minute map review (owner + one other person)

Use this if you are not solo.

> “We’re not redesigning the company. We’re writing down what happened on three real jobs. I’ll read Job A. You stop me when I skip a step you remember. We have 25 minutes. At the end we pick the three steps that hurt most.”

Timer on the table. No strategy talk. If someone says “we should productize,” write it in a parking lot and return to the map.

## Done when

You can answer, in one sentence each:

1. What is our default path from first email to kickoff?
2. Who is allowed to tell a client “yes”?
3. Who is allowed to send an invoice?
4. What is the single slowest step on last month’s jobs?

Print the map. Lesson 2 turns the circled steps into SOPs a Tuesday stand-in can follow.
